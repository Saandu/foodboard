# Screenshots referenced by the README

Two images, both committed to this folder. Delete this file once they are in.

### `menu-mobile.png` — the published menu

What a diner sees. Open
[trattoria-mareluna](https://foodboard-demo.web.app/menu/trattoria-mareluna) at
a phone width (375–430px, e.g. Chrome DevTools "iPhone 14 Pro") and capture
from the top of the hero down through two or three dishes, so the header, the
category pills, a price row and a dish photo are all visible.

### `editor.png` — the menu editor

The dashboard doing the thing the product is for. Sign in, open a category, and
capture a dish's edit modal with the per-language tabs visible — that is the
part of the interface worth showing. Desktop width, roughly 1280×800.

### Both
